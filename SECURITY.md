# Security

When private reporting is enabled, report vulnerabilities through the repository's
[Report a vulnerability](https://github.com/ntts9990/underwrite/security/advisories/new)
page. Include affected versions, a minimal reproduction, the expected trust
boundary, and the observed impact. Do not include live credentials or private
customer data.

If private reporting is unavailable, ask for a private contact through the
[maintainer's GitHub profile](https://github.com/ntts9990). A public issue should
only request a private reporting channel and contain no vulnerability details.

Security fixes are developed against the current main branch. No support period
or response deadline is promised. Keep dependencies and your installed version
current, and review the limitations reported with each evidence result.
