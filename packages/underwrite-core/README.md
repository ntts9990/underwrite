# underwrite-core

Dependency-free Python primitives for canonical serialization, content seals,
evidence chains, receipts, population checks, vocabulary boundaries, registries,
and bundles. Requires Python 3.12 or later.

This package performs pure computations using the Python standard library. Local
file access and CLI operations belong to the companion `underwrite` package.
